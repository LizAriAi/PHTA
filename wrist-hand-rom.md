# Wrist & Hand Range of Motion (ROM)

## Wrist
| Motion | Normal Range |
|--------|--------------|
| Flexion | 68° → 80° |
| Extension | 60° → 75° |
| Radial Deviation | 20° → 25° |
| Ulnar Deviation | 30° → 40° |

## Fingers - Flexion
| Joint | Normal Range |
|-------|--------------|
| MCP | 90° - 100° |
| PIP | 100° - 110° |
| DIP | 70° - 90° |

## Fingers - Extension
| Joint | Normal Range |
|-------|--------------|
| MCP | 45° |
| PIP | 0° |
| DIP | 0° |

## Thumb - CMC
| Motion | Normal Range |
|--------|--------------|
| Flexion | 15° - 25° |
| Extension | 15° - 35° |
| Abduction | 40° - 50° |
| Adduction | ~15° (not typically measured - return to neutral) |

## Thumb - MCP & IP
| Motion | Normal Range |
|--------|--------------|
| Flexion | 80° |
| Extension | 20° - 30° |

## Thumb - Opposition
- Measure tip to tip of fingers
- Should be able to touch
- Look for decreasing distance between fingertips and palm
- No normal value (functional test)
